# 易班 · 网络易指数 一键提交全部

一个油猴（Tampermonkey）脚本，解决易班「网络易指数申报」后台的三个痛点：

| 功能 | 说明 |
| --- | --- |
| **一键提交全部** | 自动逐条走「编辑 → 编辑页底部提交 → 返回列表」，一条接一条，跑完自动停 |
| **提交按钮状态着色** | 不用点任何按钮：每行的「提交」按钮**绿色=已提交，红色=未提交**（草稿/被退回算未提交） |
| **自动翻页** | 一页跑完自动切下一页，直到最后一页（也可限制「只跑前 N 页」，比如只跑第 1、2 页）|
| **横向滚轮** | 给超宽表格补上横向滚动条；MDC 固定表格的「表头 / 表体 / 表尾」三块容器滚动位置同步 |

## 为什么必须走「编辑 → 提交」

站点自身有个时间字段的坑：**列表里那排「提交」按钮点了不生效**（只在编辑页里提交才真正写状态）。
所以脚本不会去点列表里的提交键，而是：

```
点该行「编辑」→ 等编辑页出现（底部 footer 的「提交」）→ 点它
   → 若有确认弹窗就点「确定」→ 等成功提示/回到列表 → 点「返回」→ 下一条
```

列表里那个按钮只用来**显示颜色**，不参与提交。

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）。
2. 打开脚本原始文件，油猴会提示安装：

   ```
   https://raw.githubusercontent.com/foweh/yiban-yizhishu-oneshot/main/yiban-yizhishu-oneshot.user.js
   ```

   或者：油猴面板 → 添加新脚本 → 把 `yiban-yizhishu-oneshot.user.js` 全文粘进去 → Ctrl+S 保存。

脚本匹配 `*://*.yiban.cn/*`，在易班后台页面自动生效，右下角会出现「易班提效」小面板。

## 用法

1. 打开**申报列表页**（有「编辑 / 提交」那一列的那页）。
2. 面板会自动显示 `未提交 N · 已提交 M`，同时每行按钮已按状态上色。
3. 先勾上 **「干跑」** 跑一遍（只走流程不真提交），确认日志里每条都能找到编辑页 → 提交键，再取消勾选正式跑。
4. **「最多跑 N 页」**：`0` = 所有页（一直翻到最后一页）；填 `2` = 只跑第 1、2 页。面板右侧会显示 `第 X/11 页 · 共 204 条`。
5. 点 **「一键提交全部」**，看日志逐条推进；中途想停就点「停止」（当前这条处理完就停）。
6. **间隔**（默认 900ms）可以调大一点更稳，避免触发站点风控。

### 翻页是怎么做的

- 总页数来自「跳页」输入框的 `max` 属性（这份数据 `max=11`，对应 `共 204 条` / 每页 20 条）；取不到就退回「页码按钮里最大的数字」。
- 每轮先用**页码按钮**切到目标页；页码被 `...` 折叠点不到时，改用**跳页输入框**：写值 → 触发 `input/change` → 派发 `Enter`。
- 站点在「编辑页 → 返回」后**经常把你带回第 1 页**，所以每条提交完都会重新 `gotoPage(目标页)`，日志里会打一句 `（列表跳回第 1 页，切回第 5 页）`。
- 某条一直失败（校验不过）会记进 `tried` 集合跳过，不会在同一行上死循环。

日志示例：

```
[14:02:10] 开工：共 204 条 / 11 页，只跑前 2 页
[14:02:11] —— 第 1/11 页：待提交 20 条
[14:02:11] #1 id=287363 [草稿] 点「编辑」
[14:02:14] #1 id=287363 [草稿] 点编辑页「提交」
[14:02:17] #1 id=287363 [草稿] ✓ 提交完成（已返回列表）
[14:02:18] （列表跳回第 1 页，切回第 1 页）
...
[14:05:30] —— 第 1/11 页：没有待提交的了，翻下一页
[14:05:31] —— 第 2/11 页：待提交 20 条
...
[14:09:52] 已跑满设定的 2 页，停止
[14:09:52] 结束：成功 40 条，失败/跳过 0 条
```

## 状态着色规则

| 状态文字 | 颜色 | 含义 |
| --- | --- | --- |
| 草稿 / 待提交 / 未提交 / 被退回 / 退回 / 不通过 | 🔴 红 | 还没提交（或被打回） |
| 其它（已提交 / 审核中 / 已通过 / 已计分 …） | 🟢 绿 | 已经交上去了 |

有的状态下站点会把「提交」按钮藏起来，那脚本就改成给**状态单元格**染色。

## 横向滚轮

- 易指数列表用的是 MDC 固定表格，实际是三块容器（`fixed-header` / `fixed-body` / `fixed-footer`）拼出来的，
  默认不横向滚动 → 脚本给三块都加 `overflow-x:auto` 并**互相同步 `scrollLeft`**，滚动时表头和内容不会错位。
- 「申报管理系统」那类 AdminLTE 页面用的是 `.table-responsive`，常被父级 `overflow` 裁掉 → 强制补 `overflow-x:auto`。
- 兜底：任何 `table` 比父容器宽却没有滚动条时，直接给父容器加。

## 已知限制

- 依赖站点 DOM（`tr.mdc-data-table__row`、`td.status-*`、`footer.application-footer`、按钮文案「编辑 / 提交 / 返回」）。站点改版就要同步改选择器。
- **提交不可撤销**（有的状态可以撤回，有的不行）——所以提供「干跑」，先在 1~2 条上试。
- 只做「按下去的自动化」，不做任何接口伪造；所有动作都是真人点的同一套按钮。
- 分页切换后会自动重新扫描（每轮都重新读 DOM），不用手动刷新。
